These files are for ADVANCED users / developers only.
Normal users do NOT need anything in this folder.

  install.bat        - older step-by-step installer (SETUP.bat replaces it)
  build-exe.bat      - builds the .exe by itself (SETUP.bat already does this)
  set-default.bat    - registers PDF association by itself (SETUP.bat does this)
  run-debug.bat      - starts the app with a console window for error messages
  installer.iss      - Inno Setup script to build a setup.exe installer
  INSTALLER_GUIDE.md - full technical guide for building installers

To install the app normally, just use SETUP.bat in the main folder.
